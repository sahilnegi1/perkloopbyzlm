Email server settings

Brevo SMTP settings

The Brevo SMTP settings are smtp-relay.brevo.com on port 587 (or 2525), or on port 465 with SSL/TLS. The user name is the SMTP login shown in your SMTP & API settings, and the password is an SMTP key, not an API key and not your account password.

Last checked October 10, 2026, against Brevo’s own documentation.

Brevo SMTP settings explained

From Brevo’s help article Send transactional emails using Brevo SMTP and its port guide:

  • Server: smtp-relay.brevo.com.
  • Port 587: Brevo recommends starting with it as the default, and its port guide names 587 for TLS connections. The setup article says to leave the app’s encryption field empty unless you use port 465.
  • Port 2525: the alternative when 587 is blocked. Brevo notes that it “is not an officially recognized SMTP port by IETF or IANA”, but most ISPs and cloud hosts support it.
  • Port 465: for SSL; select SSL or TLS in the app.
  • Brevo’s troubleshooting page sums it up: “Brevo SMTP supports ports 587, 465, and 2525.”

SMTP login and SMTP key

The SMTP relay uses its own login, separate from your account sign-in (Brevo):

  • SMTP login: either your Brevo account email or “an automatically generated address in the format [ID]@smtp-brevo.com”. Changing your account’s login email doesn’t change the SMTP login.
  • Password: an SMTP key from the SMTP page of your settings (SMTP & API). Copy an existing key or generate a new one if you didn’t save it. Brevo: “Make sure you are using an SMTP key and not an API key.”

Before you send: domain, senders and Postfix

  1. Add and authenticate your domain. Brevo lists this as the first step and links to its DKIM setup; background: DKIM record.
  2. Create and configure your transactional senders.
  3. Enter the settings in your app or plugin: host, port, SMTP login and SMTP key.

For a Postfix server, Brevo’s developer guide relays through port 587:

# /etc/postfix/main.cf
relayhost = [smtp-relay.brevo.com]:587

# /etc/postfix/sasl_passwd
[smtp-relay.brevo.com]:587 USERNAME:master_password

Replace USERNAME with your SMTP login and master_password with your SMTP key. If the relay doesn’t accept IPv6 connections, Brevo suggests setting inet_protocols to IPv4 in main.cf.

What the Brevo SMTP relay is for

Brevo’s developer documentation describe the SMTP relay as “designed for transactional emails”. It doesn’t support batch sending; for that, Brevo points to the batch sending endpoints of its API.

Brevo blocks contacts after hard bounces, so a mistyped address at sign-up ends up on the blocked list. Check addresses when they’re entered with an email validation API, or clean an imported list with the bulk email verifier first.

Brevo SMTP settings: FAQ

What are the Brevo SMTP settings?

Server smtp-relay.brevo.com, port 587 (or 2525) with the app’s encryption field left empty, or port 465 with SSL/TLS. User name: your SMTP login; password: an SMTP key.

What is my Brevo SMTP username?

The SMTP login shown under SMTP & API in your Brevo settings: your account email or a generated [ID]@smtp-brevo.com address.

Can I use a Brevo API key as the SMTP password?

No. The SMTP relay needs an SMTP key, which you copy or generate on the SMTP page of your SMTP & API settings.

Which port should I use for Brevo SMTP?

Start with 587. Use 465 for an SSL connection, and 2525 if your hosting provider blocks 587.

Why does Brevo say “Unauthorized IP address”?

The 525 5.7.1 error means blocking of unknown IPs is on and the IP your server sends from isn’t on your list of authorized IPs. Add the actual outbound IP in Brevo.
